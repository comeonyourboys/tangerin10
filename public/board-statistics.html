What 100,000 Tangerine 10 boards look like

Every Tangerine 10 game deals a new random board. To see what a "typical" board actually contains, we generated 100,000 desktop boards and 100,000 mobile boards with the game's own board code and counted every move available before the first drag.

How the simulation works

The game builds a board with one line of code: every cell receives a whole number from 1 to 9, each equally likely, independent of its neighbours. There is no shuffling of a fixed deck, no guarantee of a certain number of nines and no check that the board is solvable. The simulation reproduces that line exactly and then looks at the board the way the selection box does.

A move here means any rectangle whose tangerines add up to exactly ten. On a fresh board nothing has been cleared yet, so a rectangle selects every tangerine inside it. That has a useful consequence: two tangerines can only be cleared together as a pair if they sit directly next to each other, horizontally or vertically. Any larger rectangle would sweep up a third tangerine. Diagonal neighbours need a 2×2 box, which always holds four numbers.

Desktop boards are 10 rows by 17 columns (170 tangerines). Phones narrower than 600 pixels get 12 rows by 14 columns (168 tangerines). Both were simulated separately because the shape changes how many cells sit on an edge, and edges matter more than you might expect.

How many moves a new board offers

The average fresh desktop board offers 54.65 distinct rectangles that add up to ten. That number varies far less than intuition suggests. Nine boards out of ten fall between 45 and 64 moves, the thinnest board in the whole run had 25, and the richest had 89. Mobile boards are almost identical: 54.24 moves on average, between 45 and 64 for nine boards in ten.

Two figures stand out. First, pairs dominate: 34.77 of the 54.65 opening moves on a desktop board are two adjacent tangerines. Second, not a single board in 200,000 started without a pair. The leanest board still had 11 of them, so a game can never open with nothing to do.

The distribution is a bell curve centred in the mid-thirties. That is what you would expect from a board of 170 independent cells: a desktop board has 313 horizontal and vertical neighbour links, and each link is a pair with probability 9 in 81, or one in nine. 313 divided by nine is 34.8, and the simulation landed on 34.77. The arithmetic and the simulation agree, which is a good sign that the simulation is counting the right thing.

Every digit is equally common, but not equally useful

Each digit appears about 18.91 times on a desktop board, exactly as a uniform draw predicts. Each tangerine also has, on average, about 0.409 neighbours that complete a pair with it, whatever its number. The difference between digits shows up somewhere else: in how many tangerines of each number are part of no move at all when the game begins.

The pattern is a clean staircase. Only 21.11% of ones are stuck at the start, against 64.94% of nines. The reason is that small numbers have more ways to reach ten. A 1 can finish a pair with a 9, but it can also sit inside 1+2+7, 1+3+6, 1+4+5, 1+1+8 and a dozen longer combinations. A 9 has exactly one possible partner. Every step up the number line removes options, and in the table each step up adds between 4.3 and 6.0 percentage points.

How often a 9 starts stranded

For a 9, "in no move" has a precise meaning: none of the cells touching it holds a 1. That can be checked with plain probability, which gives a second, independent way to test the simulation. Each neighbour is a 1 with probability one in nine, so a 9 in the middle of the board (four neighbours) is stranded with probability (8/9)4 = 62.4%. On an edge it has three neighbours, (8/9)3 = 70.2%; in a corner two, (8/9)2 = 79.0%.

Weighting by how many cells of each kind exist gives 64.93% for the whole board. The simulation measured 64.94%. Roughly two nines in three start the game with no way out.

There is also a harder limit that no amount of skill gets around. A 9 can only ever leave the board together with exactly one 1, and each 1 can only be used once. On 46.77% of desktop boards the nines outnumber the ones, and on average 2.45 nines per board have no 1 left to pair with even in a perfect game. On the most lopsided board in the run, 25 nines were left without a possible partner. Since ones also disappear into combinations like 1+2+7, the real number of unclearable nines in a typical game is higher still.

What the numbers mean for a player

Three practical readings follow from the data. A fresh board is never empty of options: there are always dozens of pairs, so a slow opening is a scanning problem, not a board problem. Big boxes are rare at the start and grow more common only as holes open up, which you can see in the bot experiment. And nines are the least useful number on the board by a wide margin. How to turn that into a habit is covered in the strategy guide, so it is not repeated here. The complete list of combinations, with odds, is on the make-ten combinations page.

Reproducing these numbers

Everything on this page comes from one script, scripts/simulate.mjs, run with Node.js. It copies the game's makeBoard line exactly — each cell gets Math.floor(random × 9) + 1 — but swaps the browser's random number generator for a seeded one (seed 20261020) so the same run produces the same numbers every time. The script writes its results to a JSON file, and this page is built from that file, so no figure here was typed by hand. Change the seed and the decimals will move a little; the conclusions will not.
